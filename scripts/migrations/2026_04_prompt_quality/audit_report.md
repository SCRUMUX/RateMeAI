## Category B — flexible/semi lock with empty overrides_allowed

After Phase 2 the styles also flagged in Category A get populated

migration need manual curation.

> ✅ **Resolved (May 2026):** the v3 migration replaces
> `overrides_allowed` with `scene_overrides`, and every style now

> code path.

## Category C — empty quality_identity.base

All 126 v2 styles ship with `quality_identity.base = ""`. The model
wrappers fall back to the legacy `QUALITY_PHOTO` block, so this is a
missed-opportunity rather than a defect. Out of scope for v1.27.2 —
tracked for ongoing admin-panel curation.

> ⏳ **Still open (May 2026):** the v3 schema preserves
> `quality_identity` unchanged, so this audit item carries over.
> See `docs/prompt-pipeline-v3.md` §"Future work" — the plan is to
> bind `quality_identity.base` to model family (FLUX / GPT-Image / SD)
> rather than per-style, so curation cost stays manageable.
